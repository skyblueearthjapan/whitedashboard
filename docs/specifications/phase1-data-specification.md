# Phase 1：データ仕様

（Spreadsheet を設計DBとして扱う）

## 1. このフェーズの目的

本フェーズの目的は、
**Google スプレッドシートを「設計データベース（DB）」として正式定義し、
アプリケーション実装側が迷わず読み取れる状態にすること**である。

- スプレッドシートは UI 設定・構成定義の **唯一の正（Single Source of Truth）**
- コード側は「シートの意味」を解釈して描画する
- UIや挙動の変更は **コードではなくデータで行う**

---

## 2. 全体構造（シート一覧）

本プロジェクトでは、以下のシート構成を前提とする。

| シート名 | 役割 |
|---|---|
| 00_はじめに | 目的・思想・運用メモ |
| 01_ページ | ページ（タブ）定義 |
| 02_ウィジェット | 置く部品の台帳 |
| 03_レイアウト | 配置定義（PC/Tablet/Mobile） |
| 04_アセット | 画像・PDF・アイコン台帳 |
| 05_参照リスト | ドロップダウン用定義 |
| 06_HTML本文 | HTML / Markdown 本文 |
| 90〜92_プレビュー | 配置確認（設計補助） |

※ 業務データ（日報・申請内容など）は **一切含まれない**

---

## 3. 基本設計原則

### 3.1 データ駆動

- UI構成・配置・ページ切替は **すべてシート定義から生成**
- 条件分岐や例外は極力持たない

### 3.2 拡張耐性

- 列の追加は許容
- 既存列の意味変更は禁止
- enum（link / embed 等）は **コード値として扱う**

---

## 4. 01_ページ（Pages）

### 4.1 役割

- ポータル内の **ページ（タブ）** を定義する
- 全社 / 部署別 / 用途別 の単位

### 4.2 主な列定義

| 列名 | 意味 |
|---|---|
| ページID | 内部識別子（ユニーク） |
| ページタイトル | 表示名 |
| 表示順 | タブ順 |
| レイアウトモード | auto / manual / hybrid |
| 列数_PC | PC時のグリッド列数 |
| 列数_タブレット | タブレット時 |
| 列数_モバイル | モバイル時 |
| 行高さ(px) | グリッド1行の高さ |
| 余白(px) | ウィジェット間余白 |
| 背景色 | ページ背景 |
| ヘッダーアセットID | ヘッダー画像参照 |
| メモ | 運用用 |

### 4.3 ルール

- 初期状態は `home` 1ページのみ
- ページ追加 = 行追加
- ページ削除 = 行削除（参照ウィジェットがないことを前提）

---

## 5. 02_ウィジェット（Widgets）

### 5.1 役割

- キャンバス上に置ける **最小単位の部品台帳**

### 5.2 ウィジェット種別（type）

以下は **コード値**として扱う。

| type | 説明 |
|---|---|
| link | リンク/ボタン |
| embed | 埋め込み（iframe） |
| image | 画像 |
| pdf | PDF |
| sheet | Googleスプレッドシート |
| html | HTML / Markdown |
| text | テキスト |
| divider | 区切り |

### 5.3 主な列定義

| 列名 | 意味 |
|---|---|
| ウィジェットID | 一意なID |
| タイトル | 表示名 |
| 種別 | 上記 type |
| 既定ページ | 初期表示ページ |
| 対象 | all / admin / soumu 等 |
| URL/参照 | URL または REF:XXX |
| アイコンアセットID | 表示用アイコン |
| 開き方 | same_tab / new_tab |
| 埋め込み方式 | iframe / link_fallback |
| 表示 | TRUE / FALSE |
| 管理者 | 責任者 |
| 棚卸周期 | monthly / quarterly 等 |

### 5.4 ルール

- 1行 = 1ウィジェット
- 中身の責任は **ポータルではなく各アプリ側**
- 非表示でも定義は残す（削除しない）

---

## 6. 03_レイアウト（Layout）

### 6.1 役割

- 各ページ・各ブレイクポイントでの **配置とサイズ**

### 6.2 ブレイクポイント

| コード値 | 対象デバイス |
|---|---|
| PC | デスクトップ |
| TABLET | タブレット |
| MOBILE | スマートフォン |

### 6.3 主な列定義

| 列名 | 意味 |
|---|---|
| ウィジェットID | 対象ウィジェット |
| ページID | 表示ページ |
| ブレイクポイント | PC / TABLET / MOBILE |
| X | 左上X座標 |
| Y | 左上Y座標 |
| 幅(w) | 横マス数 |
| 高さ(h) | 縦マス数 |
| 自動配置 | TRUE / FALSE |
| 固定 | TRUE / FALSE |
| 重なり順 | z-index |

### 6.4 ルール

- auto=TRUE の場合、X/Yは空欄可
- manual配置が auto より優先
- 同一ページ・同一BPで衝突が起きないことを前提
- レイアウト計算は **実装側責務**

---

## 7. 04_アセット（Assets）

### 7.1 役割

- 画像 / PDF / アイコンなどの **参照台帳**

### 7.2 主な列定義

| 列名 | 意味 |
|---|---|
| アセットID | 一意 |
| アセット種別 | image / icon / pdf |
| 参照元URL/ID | Drive URL 等 |
| 代替テキスト | アクセシビリティ |
| 管理者 | 責任者 |
| 更新日 | 最終更新 |
| メモ | 備考 |

---

## 8. 06_HTML本文

### 8.1 役割

- HTML / Markdown の本文管理
- ウィジェット側から参照される

### 8.2 参照方法

- 02_ウィジェット.URL/参照 = `REF:HTML_xxx`
- 実装側は該当行を引いて描画

### 8.3 ルール

- format=markdown を基本推奨
- 生HTMLは限定管理者のみ

---

## 9. 05_参照リスト（Lookups）

### 9.1 役割

- ドロップダウン選択肢の **定義専用**
- 実装では enum 値として利用

### 9.2 ルール

- UI表示用翻訳は実装側で対応
- 値そのものは変更しない

---

## 10. データ更新ポリシー

- 編集権限者のみ更新可能
- 更新履歴はスプレッドシート側で保持
- 将来、履歴ログはアプリ側で拡張予定

---

## 11. Phase 1 完了条件（Definition of Done）

- 各シート・各列の意味が明文化されている
- 実装者が **UIを想像せずにデータ構造だけで理解できる**
- Phase 2（UI/UX仕様）に進める状態
