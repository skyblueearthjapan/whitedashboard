# Phase 10：運用UI（総務向け管理画面）設計仕様

（シートを直接触らずに、安全に運用する）

## 1. このフェーズの目的

本フェーズの目的は、
**総務（編集者）が Google スプレッドシートを直接編集せずに、
ポータルを安全・確実に運用できる管理UI**を設計すること。

- 誤操作を防ぐ
- 変更理由・履歴を残す
- v0（直編集）→ v1（管理UI）へ自然に移行できる

---

## 2. 管理UIの基本思想

| 原則 | 内容 |
|------|------|
| 安全優先 | 管理UIは「便利」より **安全** |
| DB連動 | すべての変更は **設計DB（Sheets）に反映** |
| 確認必須 | 破壊的操作は必ず確認 |
| 復旧可能 | 失敗しても復旧できる（Phase5の監査と連動） |

---

## 3. 管理UIの画面一覧

### 3.1 画面構成（最小）

| パス | 画面名 | 内容 |
|------|--------|------|
| `/admin` | 管理トップ | ダッシュボード |
| `/admin/pages` | ページ管理 | ページの追加・編集・並び替え |
| `/admin/widgets` | ウィジェット管理 | ウィジェットの追加・編集 |
| `/admin/assets` | アセット管理 | 画像・PDF管理 |
| `/admin/html` | HTML/Markdown管理 | コンテンツ編集 |
| `/admin/audit` | 監査ログ閲覧 | 参照のみ |

※ すべて **Editor以上のみアクセス可**

---

## 4. 管理トップ（/admin）

### 4.1 表示内容

| 項目 | 内容 |
|------|------|
| ページ数 | 全体のページ数 |
| ウィジェット数 | 表示中 / 非表示 |
| エラー・警告数 | URL未設定、参照切れ（REF/ASSET）、manual衝突 |
| 棚卸アラート | 期限切れ/期限近い |

### 4.2 目的

- 「今どこが危ないか」を一目で把握できる

---

## 5. ページ管理（/admin/pages）

### 5.1 一覧表示

| 列 | 内容 |
|----|------|
| ページID | 識別子 |
| ページタイトル | 表示名 |
| 表示順 | タブ順 |
| 対象 | 全社/部署 |
| 表示/非表示 | 状態 |
| 最終更新 | 更新日時 |

### 5.2 操作

| 操作 | 内容 |
|------|------|
| ページ追加 | page_id（必須）、page_title、初期レイアウト（auto推奨） |
| ページ名変更 | タイトル編集 |
| 表示順変更 | ドラッグ or 数値入力 |
| 非表示 | 削除ではなく非表示化 |

### 5.3 制約

- page_id の重複は禁止
- 非表示ページでも参照ウィジェットは保持

---

## 6. ウィジェット管理（/admin/widgets）

### 6.1 一覧表示

| 列 | 内容 |
|----|------|
| ウィジェットID | 識別子 |
| タイトル | 表示名 |
| 種別 | link/embed/image/pdf/sheet/html |
| 既定ページ | 初期表示ページ |
| 表示/非表示 | 状態 |
| 管理者（owner） | 責任者 |
| 棚卸周期 | review_cycle |

### 6.2 操作

| 操作 | 内容 |
|------|------|
| 追加 | 新規ウィジェット作成 |
| 編集 | タイトル、URL/参照、種別、開き方/埋め込み方式、アイコン、管理者/棚卸周期 |
| 表示/非表示切替 | soft delete |
| 既定ページ変更 | ページ割り当て変更 |

### 6.3 安全装置

| 対策 | 内容 |
|------|------|
| 種別変更警告 | embed→link 等の変更時は警告 |
| URL必須 | URL未設定では保存不可（推奨） |
| 参照切れ警告 | 参照先がない場合は警告表示 |

---

## 7. アセット管理（/admin/assets）

### 7.1 対象

- 画像（ヘッダー/カード/アイコン）
- PDF

### 7.2 操作

| 操作 | 内容 |
|------|------|
| アセット追加 | 種別、URL / DriveファイルID、代替テキスト |
| 参照先一覧 | どのウィジェット/ページで使われているか表示 |

### 7.3 制約

- 使用中アセットは削除不可
- 削除は非表示（論理削除）を基本

---

## 8. HTML / Markdown 管理（/admin/html）

### 8.1 一覧

| 列 | 内容 |
|----|------|
| content_id | 識別子 |
| 種別 | markdown/html |
| 使用ウィジェット数 | 参照数 |
| 最終更新 | 更新日時 |

### 8.2 編集体験

| 機能 | 内容 |
|------|------|
| エディタ | Markdownエディタ（推奨） |
| プレビュー | リアルタイムプレビュー表示 |
| 生HTML | Admin のみ編集可（将来） |

### 8.3 安全対策

| 対策 | 内容 |
|------|------|
| Markdown | サニタイズ前提 |
| 生HTML | 警告表示 |

---

## 9. 監査ログ閲覧（/admin/audit）

### 9.1 表示項目

| 列 | 内容 |
|----|------|
| 日時 | 変更日時 |
| 変更者 | actor |
| 対象 | page / widget / layout |
| 操作種別 | create/update/delete |
| 差分 | before / after |

### 9.2 操作

| 機能 | 内容 |
|------|------|
| フィルタ | 期間 / 対象 / 変更者 |
| 詳細表示 | JSON形式で差分表示 |

※ ロールバックは v2 以降でも可

---

## 10. 保存と反映のルール

| ルール | 内容 |
|--------|------|
| API経由 | すべての管理UI操作は API 経由で Sheets を更新 |
| 監査ログ | 更新時に必ず監査ログを残す |
| エラー処理 | 更新失敗時は UI にエラーを表示し反映しない |

---

## 11. 誤操作防止（UX要件）

| 対策 | 内容 |
|------|------|
| 確認ダイアログ | 削除・非表示は必ず確認 |
| 影響範囲明示 | 例：「このウィジェットは home ページに表示されています」 |
| 入力チェック | 保存前にバリデーション |

---

## 12. 管理UI画面フロー

```
/admin（ダッシュボード）
    │
    ├── /admin/pages ────── ページ追加/編集
    │
    ├── /admin/widgets ──── ウィジェット追加/編集
    │                           │
    │                           └── アイコン選択 → /admin/assets
    │                           └── HTML参照 → /admin/html
    │
    ├── /admin/assets ───── アセット追加/管理
    │
    ├── /admin/html ─────── HTML/Markdown編集
    │
    └── /admin/audit ────── 監査ログ閲覧（読み取り専用）
```

- 誤操作が起きにくい
- 何か起きても監査ログで追える
- v0 → v1 移行が自然にできる
