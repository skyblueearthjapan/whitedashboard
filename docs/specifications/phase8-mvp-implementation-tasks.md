# Phase 8：MVP（v0）実装タスク分解

（コーディングエージェント 実行指示書）

## 1. このフェーズの目的

本フェーズの目的は、Phase0〜7で確定した仕様をもとに、
**MVP（v0）を確実に完成させるための実装タスクを、順序付き・依存関係付きで分解すること**である。

- 各タスクは「実装 → 動作確認 → 次へ」できる粒度
- UI/UXの磨き込みではなく **まず"動く土台"を完成させる**
- 途中で仕様判断が必要にならないよう、前提を明記する

---

## 2. 実装の前提（再確認）

| 前提 | 内容 |
|------|------|
| 設計DB | Spreadsheet（日本語版テンプレ）が唯一のソース |
| 初期ページ | `home` のみ |
| 編集者 | 限定（本人＋総務一部） |
| スコープ外 | 個人最適化・高度検索は v0 では行わない |
| フォールバック | embedは失敗しても必ず link で開ける |

---

## 3. 実装フェーズ全体像（順序）

**必ずこの順で進めることを推奨する**

```
1. データ取得（Sheets → 内部モデル）
       ↓
2. 閲覧モードでの表示
       ↓
3. レイアウトエンジン（manual + auto）
       ↓
4. 端末別（BP）切替
       ↓
5. 編集モード（ドラッグ・リサイズ）
       ↓
6. 保存（Sheets書き戻し）
       ↓
7. 監査ログ
       ↓
8. 権限ガード
```

---

## 4. タスク一覧（MVP v0）

### Task 1：Sheets 設計DB 読み取り基盤

**目的**：すべての土台

| 実装内容 | 詳細 |
|---------|------|
| API | Google Sheets API で以下を取得 |
| 対象シート | 01_ページ / 02_ウィジェット / 03_レイアウト / 04_アセット / 06_HTML本文 |
| マッピング | 列名 → 内部キーへ変換 |
| 正規化 | 数値/Booleanの正規化（"TRUE"/"FALSE" 等） |

**完了条件**
- `getConfig()` で全設定がJSONとして取得できる

---

### Task 2：内部データモデル定義

**目的**：実装の安定化

| 型 | 説明 |
|----|------|
| Page | ページ定義 |
| Widget | ウィジェット定義 |
| LayoutRow | レイアウト行 |
| Asset | アセット |
| HtmlContent | HTML本文 |

- widget_id / page_id をキーに参照関係を組み立てる

**完了条件**
- config JSON から内部モデルへ変換できる

---

### Task 3：閲覧モード・ページ表示（最小）

**目的**：まず「見える」状態にする

- `home` ページを表示
- 01_ページ に基づきページ切替UIを表示
- visible=FALSE は表示しない

**完了条件**
- `home` が表示され、空でもエラーにならない

---

### Task 4：Canvas（グリッド）描画

**目的**：ホワイトボードの土台

| 実装内容 | 詳細 |
|---------|------|
| 列数切替 | PC / Tablet / Mobile |
| 背景 | 背景色・ヘッダー画像表示（あれば） |
| スクロール | 縦スクロール可能なキャンバス |

**完了条件**
- 端末切替でグリッド列数が変わる

---

### Task 5：WidgetRenderer（type分岐）

**目的**：ウィジェットを描画する

| type | 表示 |
|------|------|
| link | カード＋遷移 |
| embed | iframe表示 |
| image | 画像表示 |
| pdf | リンク表示 |
| sheet | リンク表示 |
| html | markdown表示 |

**完了条件**
- typeごとに表示され、エラーなく描画される

---

### Task 6：レイアウトエンジン（Phase3準拠）

**目的**：崩れない配置

| 実装内容 | 詳細 |
|---------|------|
| manual優先 | manual配置を先に配置 |
| auto探索 | auto配置を order順に探索配置 |
| BP独立 | BPごとに独立して計算 |

**完了条件**
- manual + auto が混在しても崩れない
- 同じ入力で毎回同じ結果になる（決定的）

---

### Task 7：端末別プレビュー切替

**目的**：編集前提の確認機能

- PC / Tablet / Mobile 切替UI
- 切替時に 03_レイアウト.bp を切り替えて再描画

**完了条件**
- BP切替で配置が変わる

---

### Task 8：編集モードON/OFF

**目的**：閲覧と編集の分離

| 実装内容 | 詳細 |
|---------|------|
| 切替ボタン | 編集モード切替 |
| 表示制御 | Viewerには表示しない |
| 操作UI | 編集モード時のみ操作UIを表示 |

**完了条件**
- 閲覧モードでは一切動かせない

---

### Task 9：ドラッグ移動（グリッドスナップ）

**目的**：配置変更

| 実装内容 | 詳細 |
|---------|------|
| ドラッグ | ウィジェットをドラッグで移動 |
| スナップ | グリッド単位でスナップ |
| 衝突回避 | 移動中は衝突を視覚的に回避 |

**完了条件**
- 移動後、位置が内部状態に反映される

---

### Task 10：リサイズ（w/h変更）

**目的**：サイズ調整

| 実装内容 | 詳細 |
|---------|------|
| ハンドル | ハンドル操作でリサイズ |
| 更新 | w/h をグリッド単位で更新 |
| 制限 | 最小サイズ制限あり |

**完了条件**
- リサイズ後もレイアウトが破綻しない

---

### Task 11：保存（03_レイアウト書き戻し）

**目的**：設定を永続化

| 実装内容 | 詳細 |
|---------|------|
| 保存単位 | ページ単位で保存 |
| 座標保存 | auto配置の確定 x/y も含めて保存 |
| UI表示 | 保存中/成功/失敗のUI表示 |

**完了条件**
- 再読み込みしても同じ配置になる

---

### Task 12：監査ログ記録

**目的**：運用安全性

保存時にログ追加：

| 列 | 内容 |
|----|------|
| timestamp | 変更日時 |
| actor | 変更者 |
| target | page/widget |
| before | 変更前 |
| after | 変更後 |

**完了条件**
- ログシートに変更履歴が残る

---

### Task 13：権限ガード（Editorのみ）

**目的**：事故防止

| 実装内容 | 詳細 |
|---------|------|
| API制限 | 編集APIは Editor のみ実行可 |
| 直叩き拒否 | URL直叩きでも拒否（403） |

**完了条件**
- Viewerは編集できない

## 5. MVP完成判定（最終チェック）

以下がすべて満たされたら v0 完成：

| チェック | 項目 |
|----------|------|
| [ ] | homeページ表示 |
| [ ] | PC/Tablet/Mobile 切替 |
| [ ] | link/embed/image/pdf/sheet/html 表示 |
| [ ] | manual + auto レイアウト安定 |
| [ ] | 編集者のみ移動・リサイズ可能 |
| [ ] | 保存で配置が保持される |
| [ ] | 監査ログが残る |
| [ ] | embed失敗でもリンクで開ける |

---

## 6. 実装上の重要注意（必読）

| 原則 | 内容 |
|------|------|
| UIを作り込みすぎない | まず動く土台を優先 |
| シート構造を変えない | 既存列の意味変更禁止 |
| 例外はログに残す | デバッグ可能に |
| 拡張性優先 | 「あとで直せる」より「あとで拡張できる」を優先 |
